Support

For help with Would You Rather: Faith, report a problem on the project's GitHub Issues page.

Before reporting a problem

  • Include your iPhone or iPad model and iOS version.
  • Describe what you expected and what happened.
  • For translation problems, include the selected language and whether its Apple language resources were downloaded.
  • Do not include private or sensitive information.

Common translation issue

Dynamic card translation requires iOS 18 or later and an Apple-supported language pair. iOS may ask you to download the selected language before translation can begin.
